HashSuite – MD5 / SHA на 7 языках программирования
Мощный консольный инструмент для вычисления криптографических хешей (MD5, SHA-1, SHA-256, SHA-512).
Реализован на семи популярных языках с единым интерфейсом, расширенными возможностями и поддержкой файлов.

🚀 Возможности
Поддерживаемые алгоритмы: MD5, SHA-1, SHA-256, SHA-512.

Входные данные:

Прямой ввод текста через аргумент -t.

Чтение из файла (-i).

Чтение из стандартного ввода (если не указано иное).

Выходные форматы: шестнадцатеричный (hex) и Base64.

Сравнение хешей: проверка целостности данных (-c).

Соль (salt): добавление соли перед хешированием (-s).

Многоязычность: одинаковый синтаксис во всех реализациях.

Цветной вывод (где поддерживается) и понятные сообщения об ошибках.

📖 Использование
Синтаксис (единый для всех языков):

bash
<интерпретатор/исполняемый> [OPTIONS]
Доступные опции
Опция	Описание
-a, --algo	Алгоритм: md5, sha1, sha256, sha512 (по умолчанию sha256)
-t, --text	Текст для хеширования
-i, --input	Входной файл
-o, --output	Выходной файл (если не указан, вывод в stdout)
-s, --salt	Строка соли (добавляется перед хешированием)
-c, --compare	Хеш для сравнения (проверка целостности)
-f, --format	Формат вывода: hex (по умолчанию) или base64
-h, --help	Справка
Примеры
bash
# Хеш SHA-256 строки "Hello World"
python hash.py -a sha256 -t "Hello World"

# MD5 файла document.txt
python hash.py -a md5 -i document.txt -o hash.txt

# Сравнение хеша с вычисленным
python hash.py -a sha1 -t "secret" -c "e5e9fa1ba31ecd1ae84f75caaa474f3a663f05f4"

# Base64 вывод SHA-512 с солью
python hash.py -a sha512 -t "password" -s "randomsalt" -f base64

Установка и запуск
Python
bash

Требуется Python 3.6+ (стандартная библиотека).

Go
bash
go build hash.go
./hash [опции]
JavaScript (Node.js)
bash
node hash.js [опции]
C++
bash
g++ -std=c++11 hash.cpp -lssl -lcrypto -o hash
./hash [опции]
Требуется OpenSSL (разработческие пакеты).

C#
bash
csc hash.cs
mono hash.exe [опции]   # или dotnet run
Требуется .NET Framework / .NET Core.

Java
bash
javac hash.java
java hash [опции]
Ruby
bash
ruby hash.rb [опции]
🧠 Архитектура
Все программы построены по единому шаблону:

Парсинг аргументов командной строки.

Чтение входных данных (текст или файл).

Добавление соли (если указана).

Вычисление хеша выбранным алгоритмом.

Форматирование результата (hex/base64).

Сравнение с эталоном (если задано).

Вывод результата или запись в файл.

Благодаря этому код легко читается и адаптируется для новых алгоритмов.

✨ Дополнительные фичи
Автоопределение кодировки (везде UTF-8).

Проверка корректности алгоритма.

Поддержка больших файлов (чтение по частям в некоторых реализациях).

Цветной вывод для улучшения читаемости.

Единый код стиля во всех версиях.
